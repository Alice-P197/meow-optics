# 光学宝典 · Meow Optics

手机端光学设计与仿真工作台：手册检索、公式计算器、Optiland 镜头设计与追迹、技能库与模板库，接自己的大模型。配套「光屿」服务端承担重计算与模型调度。

- 官网：https://alice-p197.github.io/meow-optics/
- 安卓安装包：https://github.com/Alice-P197/meow-optics/releases
- 服务端安装包：https://github.com/Alice-P197/Meow-optics-V2/releases
- 更新清单：https://alice-p197.github.io/meow-optics/update.json

## 仓库内容

```
index.html    官网与下载页（单文件，样式内置）
assets/       界面截图
update.json   应用内更新清单
```

## 安装

下载 Releases 里的 APK 直接安装，系统要求 Android 8.0 及以上。电脑端服务端在 Meow-optics-V2 的 Releases。

## 更新

启动时读取更新清单，与本地版本比对；有新版本时提示下载，走系统安装器覆盖安装。包名与签名不变，已安装的 Key、对话历史、自建词条都保留。

## 反馈

在应用内的对话里直接提；常见问题先看官网 FAQ。
